# Customer Feedback Triage

`official/ora-space.customer-feedback-triage` assigns a P0-P3 priority,
classifies the issue, assesses business impact, lists missing information and
prepares a customer-ready reply. It never invents logs, metrics, root causes,
resolution times or compensation promises.

The workflow does not read project files; any Project can be selected as the
run's workspace boundary. Review the generated customer reply before sending.
