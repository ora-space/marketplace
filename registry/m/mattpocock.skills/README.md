# Matt Pocock Skills

Matt Pocock's 25 agent skills for real engineering, packaged as one static Ora
Skill plugin. The collection covers planning, TDD, debugging, code review,
architecture, domain modeling, research, handoffs, teaching, and related
engineering workflows.

The collection is synchronized from the **Mattpocock Skills** group declared by
[`mattpocock/skills`](https://github.com/mattpocock/skills). Skills outside that
upstream group, including work under `in-progress/` and `misc/`, are not bundled.

## Included skills

- ask-matt
- code-review
- codebase-design
- diagnosing-bugs
- domain-modeling
- grill-me
- grill-with-docs
- grilling
- handoff
- implement
- improve-codebase-architecture
- prototype
- research
- resolving-merge-conflicts
- setup-matt-pocock-skills
- tdd
- teach
- to-questionnaire
- to-spec
- to-tickets
- triage
- wait-what
- wayfinder
- wizard
- writing-for-agents

The plugin is static: it starts no process and grants no plugin runtime
permissions. Individual skills may still instruct an agent to use ordinary
tools or scripts as part of their documented workflow.
